# HappySmile Lead Desk

Concept prototype for the Twenty2 (Shiprocket) Product Manager case: an AI first responder plus a front-desk queue for HappySmile, a fictional chain of 12 dental clinics that gets about 300 online enquiries a day.

- **Overview** (`/`): the problem, how it works, patient personas, the 4-week scope, the success metric and the three stakeholder answers.
- **Screen 1, Patient** (`/patient`): four journeys (aligners, implants with a family decider, tooth pain, teen braces after hours), step by step, with what happens behind the scenes.
- **Screen 2, Front desk** (`/desk`): ranked lead queue, lead detail with summary and next best action, the AI-first vs control experiment, and a Rules panel.

All data is illustrative. Not an official Twenty2 or Shiprocket product.

## Run locally

```bash
npm install
npm run dev
```

Built with Vite, React and TypeScript. Deployed on Vercel.
